⚡ Compute Topology & Inference Throughput (TPS)

Comparing token generation speed across lightweight 8B dense models and GLM-5.2 (744B Mixture-of-Experts) across CPU NVMe disk-streaming (`colibri`), CPU system RAM, hybrid offloading, and dedicated multi-GPU accelerator topologies on GCP.

Key Architectural Insights

  • CPU NVMe Streaming Bottleneck: The `colibri` C-engine running GLM-5.2 on disk avoids out-of-memory errors on small VMs but yields only ~0.8 TPS. An 800-word summary takes over 20 minutes to generate, making interactive chat impossible.
  • Memory Bandwidth Stalls: RAM-resident CPU configurations (`m3-ultramem-32`) reach only 5 TPS due to DDR5 memory bus limitations when reading 380 GB weights per forward pass.
  • Multi-GPU Necessity: Frontier MoE models like GLM-5.2 require 8x A100 or 8x H100 clusters (640 GB VRAM) to achieve real-time conversational speeds (45–90 TPS single, 300–450 TPS batched).
  • 8B High Density: A single L4 GPU (`g2-standard-4`) processes 8B models at 75–500 TPS, making it an optimal microservice worker.

💰 Capacity Utilization & Direct Cost per 1M Tokens

Evaluating the unit cost per 1M tokens across varying capacity utilization profiles. Fixed 24/7 IaaS infrastructure costs inflate dramatically per token during non-peak business hours and weekend idle cycles.

The `colibri` Economic Paradox

While running `colibri` on an inexpensive CPU instance appears cheap at $0.48/hr (`c3-standard-8-lssd`), its slow speed of 0.8 TPS requires 347 continuous machine hours to produce 1 million tokens.

Result: Saturated cost is $166.67 / 1M tokens, soaring to $1,666.70 / 1M tokens at 10% enterprise duty cycles. Low-speed CPU disk streaming is economically unviable.

GPU Batching Inversion

High-cost GPU nodes ($87.83/hr for 8x H100) dramatically reduce token unit costs to $23.99–$54.22 / 1M tokens under heavy dynamic batching because they process 1M tokens in just 37 minutes.

🧭 Strategic Decision Framework & Hybrid Recommendation

Guidance for enterprise procurement and technology leadership based on workload characteristics, engineering capacity, and security requirements.

🏢

Deploy M365 Copilot SaaS ($30/seat) If:

General Knowledge Work & Teams Collaboration
  • Primary use case centers on MS Teams meeting summarization, live transcriptions, and Outlook email synthesis.
  • Internal MLOps and software engineering headcount is limited or highly constrained.
  • Document access controls are managed via SharePoint/Entra ID and must be enforced out-of-the-box.
  • Legal requires intellectual property indemnification via Microsoft's Customer Copyright Commitment (CCC).
🚀

Self-Host Open-Source on GCP If:

Specialized Domain Tasks & Air-Gapped Workloads
  • Strict regulatory requirements mandate complete VPC data isolation with zero third-party SaaS exposure.
  • High-volume, non-interactive batch workloads (e.g., millions of automated document extractions using 8B L4 GPUs).
  • Deep codebase reasoning or proprietary engineering fine-tuning on custom enterprise repositories.
  • Enterprise operates at sufficient concurrency to fully saturate multi-GPU cluster capacity 24/7.
